# Security and responsible use

## Supported version

Only the latest commit on `main` is supported during early development.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue
containing credentials, private participant information, or an exploitable proof of concept.

## Data and use boundary

This project processes only already-public, consented research datasets under their published
terms. Raw upstream files stay outside Git. The software is educational research tooling and must
not be used for diagnosis, treatment, identity inference, cognitive surveillance, or employment,
insurance, or access decisions.
