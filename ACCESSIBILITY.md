# Accessibility statement

Neuro Signal Lab targets WCAG 2.2 Level AA. The static site provides semantic landmarks,
keyboard-operable controls, visible focus, text alternatives for plotted results, reduced-motion
support, high-contrast support and reflow at 320 CSS pixels. Automated checks are release gates,
but are not a third-party conformance certification. Report barriers through a GitHub issue and
include the page, browser and assistive technology when possible; report security-sensitive details
privately under `SECURITY.md`.
